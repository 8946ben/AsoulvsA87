## 本地 UI 验证方法（踩坑记录，下次照抄）

Windows 上用系统自带 Edge 做 headless 截图，**不需要装 agent-browser（要下 500MB Chromium）**：

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" \
  --headless=new --no-sandbox --disable-gpu --no-first-run --hide-scrollbars \
  --force-device-scale-factor=1 \
  --user-data-dir="D:\game\asoulVsA87\.shots\p1" \
  --screenshot="D:\game\asoulVsA87\.shots\x.png" \
  --window-size=1280,800 --virtual-time-budget=25000 "http://127.0.0.1:5175/"
```

四个必须知道的点：

1. **要 `dangerouslyDisableSandbox`**：沙箱内 Edge 进程能起但写不出文件（静默失败、退出码 0）。
2. **截图是异步落盘的，约 30~70 秒后才出现**，必须轮询等待；早期看着"失败"其实只是还没写完。
3. **vite 默认只监听 `[::1]`**，Edge 访问 `127.0.0.1` 会 ERR_CONNECTION_REFUSED → 用 `npm run dev -- --host 127.0.0.1 --port 5175`。
4. **每个 Edge 实例必须用独立 `--user-data-dir`**，否则第二个实例会交接给第一个然后什么都不写。
5. 入场券限流会把 headless 页面挡在门外（`GAME_MAX_SLOTS=3` 三个标签页就满了）→ 本地测试用 `GAME_MAX_SLOTS=20`。

要截某个非首屏页面（如反馈页）时，临时在 `MenuScene.create()` 末尾加 `this.time.delayedCall(400, () => openChildScene(this, RelicDrawScene.KEY));`，截完**必须删掉**（`grep -rn "TEMP-SHOT" src/` 自查）。

补充两条 2026-09-13 晚踩到的：

6. **vite 必须用「托管后台任务」方式起**（`run_in_background=true` 直接跑 `npx vite`）。写成 `npx vite ... &` + `sleep` 收尾的那种，命令一结束进程就被会话清理杀掉，Edge 打开时拿到 502，截图静默不落盘。
7. **给 localStorage 存档播种**（验证「有/无藏品」「已装配」这类状态时必需）：因为 headless 截图点不了按钮，就在 `public/__seed.html` 建一个同源临时页，`localStorage.setItem(...)` 后用 `location.replace('/')` 跳回游戏 —— 同一 `--user-data-dir` 里 localStorage 同源共享，一次 Edge 运行即可。存档键 `asoul-relic-inventory-v1`，值 `{version:1, owned:RelicId[], equipped:{id:PlantType}, tickets}`；用 `location.hash` 分叉出「空存档」等用例。**用完删掉 `public/__seed.html`**（`public/` 会被复制进 dist）。
8. 新建的 `--user-data-dir` **第一次运行常常不落盘**，同一个 dir 再跑第二次就正常 —— 遇到 "STILL NO PNG" 直接原样重试，别改参数。
