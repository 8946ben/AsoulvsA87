### B 站检索方法（可复用）

`wiki.asoul.us.kg` 等维基更新滞后，找 A-SOUL 实物/梗应直接查 B 站。

- B 站搜索 API 可用且不需要登录：`https://api.bilibili.com/x/web-interface/search/type?search_type=video|article&keyword=<urlencoded>`，先 `curl -c cookies.txt https://www.bilibili.com/` 拿 `buvid3` 即可。
- 视频信息 `x/web-interface/view?bvid=`、评论 `x/v2/reply?type=1&oid=<aid>&sort=2&jsonp=jsonp`（或 `x/v2/reply/main`）、专栏 `x/article/view?id=<cv号>` 均可读；**专栏 HTML 页和弹幕接口会触发风控（验证码 / -400 / -509）**，短时间高频访问会限流，需间隔重试。
- 贴吧 `tieba.baidu.com/p/<id>` 可直接 WebFetch，开箱评测帖往往比维基更早保留真名。
- 评论/楼中楼：`x/v2/reply?type=1&oid=<aid>&sort=2&ps=20&pn=N&jsonp=jsonp`（aid 先从 `x/web-interface/view?bvid=` 取）；排序 `order=click|pubdate` 可分别拿热门与最新。
- 翻页 + 间隔 1~1.5s 未触发风控。
