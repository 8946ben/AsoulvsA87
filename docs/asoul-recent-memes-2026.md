## 二、核心新梗：AK（一个魂 × 库狗）

**这是当下枝江最大的梗，也是整个生态的骨架。**

- **AK = au + kg**
  - `au` = A-SOUL 粉丝（一个魂）
  - `kg` = 库洛 /《鸣潮》玩家（评论中大量使用「kg 兄弟」「kg 大学习」）
  - 两者合流 → **AK**，同源叫法还有 `aukg`、`aku`
- **《AK联军简史》**（BV1DUw1zPENu，UP 窄巷天空）—— 对这个现象的完整记录，文案作者是 asoul 吧 ID「花卷真的真的很好吃」。标题里的「联军」二字已是圈内固定说法。
- **「ak99」** —— 99 = 久久，弹幕用于祝两边关系长久（CP 式祝福）。
- **「已完成今日 kg 大学习」** —— 化用「青年大学习」，指每天补看直播/录播。评论区高频刷屏。
- **「潮友 / 潮 u / 库友」** —— 鸣潮玩家的自称，会主动学习 A-SOUL 历史（「新 kg 进来学习，老 kg 进来复习」）。

### 围绕它的衍生梗

| 梗 | 含义 / 出处 |
| --- | --- |
| **乃琳是鸣潮一姐** | 「鸣潮其实一直缺少一个像乃琳这样的超级流量主播」；官方切片标题「乃琳还是太超模了」（超模 = 强到破坏平衡） |
| **拼好机** | 乃琳用拼多多买的便宜机器直播鸣潮，被粉丝调侃「落魄到拼好机给乃琳直播鸣潮」 |
| **老库神了 / 巨龙腾飞** | 鸣潮玩家夸库洛的话，被 A-SOUL 粉丝借用，弹幕齐刷 |
| **长草期** | 鸣潮版本末期无内容期。有评论泼冷水提醒「鸣潮始终只是放大器」，长草期人数会回落 |
| **枝江嘴最谨慎之雕** | 乃琳知道 3.7 前瞻但「还在藏」，弹幕用「我系雕啊」的雕作呼应 |
| **一个魂来咯 / 记忆纠正** | 评论区科普长文：`A87 ⊆ AU` —— A87 只是 asoul 吧用户，不等于全体一个魂 |
