# 枝江答题题库

> 开发者题库源文件，游戏内答题玩法的唯一数据来源。
>
> **格式**：每行一道题，固定 6 列：`题干 | 选项A | 选项B | 选项C | 选项D | 答案`。
> 答案只能是 `A` / `B` / `C` / `D`，四个选项不得为空，题干内不要使用竖线 `|`。
>
> **子题库**：三个二级标题（`## A-SOUL 相关` / `## 常识题` / `## AI 与高性能计算`）对应游戏内三个子题库，答题时按 1 : 8 : 1 的比例抽取。请保留这三个章节标题；章节内的 `###` 小节仅作分类备注，不会被解析。
>
> **同步**：增删或修改题目后，运行 `npm run quiz:sync`，脚本会校验格式并生成 `src/data/quiz.generated.json`。脚本会打印各类别题量，数量不强制等于 1000，可自由增删。
