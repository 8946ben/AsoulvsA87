# 「枝江装备」扩展调研与设计建议

> 调研时间：2026-09-12
> 目的：为「枝江装备」（`src/data/relics.ts` 中的藏品系统）扩充素材池，提供可直接落地的新装备设计。
> 现状：已有 16 件藏品，覆盖 6 个数值维度（回血 / 生命 / 伤害 / 攻速 / 产出 / 费用）+ 贝拉套装联动。
> **排除项：本方案不包含任何与珈乐相关的梗（应要求排除）。**

---

## 一、结论摘要（先看这里）

1. **素材完全够用**，而且比现有 16 件用掉的多得多。三个来源：官方设定（枝江世界、枝江大学、阿草）、官方周边实物（几乎每件周边都能直接当装备：泡面碗、解压玩偶、钥匙扣、应援棒、立牌）、粉丝二创梗（水母之歌、勇敢牛牛、鸡胸肉、大凤沟）。
2. **现有 16 件的真实空缺**：`心球仪` 和 `一个魂` **一件专属装备都没有**；`嘉然 / 思诺 / 心宜 / 星空糖 / 嘉心奶糖` 各只有 1 件。新增装备应优先补这些洞。
3. **梗有分级**：约 6 成可以直接做成装备，2 成需要软化措辞，2 成建议整体规避（涉及粉丝伤痛事件、擦边内容）。
4. **最大的一句话隐患**：`background.md` 第 175 行还写着「藏品（规划中，暂未实现）」，但藏品系统已经实装并在答题题库里有题了。建议顺手改掉，否则后续 agent 同步数值时会被这行误导。

## 三、枝江元素盘点（可装备化的「物」）

### 3.1 世界观层

- **枝江**：虚构城市，原型是企划驻地杭州；一说「枝江」与杭州地名「之江」同音。与现实湖北枝江市无关，但粉丝常故意杂糅做二创。
- **枝江大学**：成员们的共同母校，推测取自浙江大学（同声母谐音）。各人专业是现成的角色抓手：社会学（向晚）、播音（贝拉）、美术（嘉然）、法学（乃琳）。
- **救场演出**：成员相遇的剧情起点，天然的「序章 / 羁绊」命名来源。
- **枝江娱乐**：官方运营厂牌（Z.J.ENTERTAINMENT），旗下还有「闪耀舞台」计划出身的心宜（Fiona）、思诺（Gladys）、AI 主播阿花。
- **旧称**：A-SOUL 团体中文名「灵境少女」（2023 中秋夜发布），组合别号「as」「A手」「欠债女团」。

### 3.2 官方实物周边（最高性价比的装备命名来源）

B 站会员购在售 / 曾售：团服手办、**脑洞波系列哈哈鬼软胶挂件**、脑洞波表情包贴纸、**晃悠悠成员摇摇立牌**、嗨呀懒洋洋趴趴公仔、二周年纪念礼盒、成员生日主题系列、**睡衣派对徽章 / 立牌 / 运动长袜 / 泡面碗**、**阿草马克杯套装**、**维特鲁威草-阿草钥匙扣**、**我不胖！-阿草解压玩偶**、**阿草 U 型枕**；《星球重启》联动的枝江限定家具：**Q萌泡面浴缸**、**懒人电竞椅**、**心之所向碗**、快乐魔盒、甜心乐园抓娃娃机。

> 这批名字的好处是「本来就是能拿在手里的东西」，做成装备毫无违和感，且没有争议。

### 3.3 阿草系（系统级吉祥物，建议成组设计）

雪貂，常被误认成羊驼，是嘉然的宠物兼团吉祥物，有时也代指工具人。**不止一只**，有白皮与黑皮两品种，黑皮称「小黑」（尼驼）。各成员的阿草以蝴蝶结颜色区分：浅蓝→向晚、橙→贝拉、黄→嘉然、深蓝→乃琳。

> 非常适合做成「一整套可换色装备」：同一件装备因装配角色不同而描述 / 数值微调。这是现有 16 件没有用到的机制空间。

## 七、阿草系列：一个未使用的机制建议

现有 16 件装备都是「固定效果 + 固定文案」。阿草是唯一一个**天然自带变体机制**的元素：

> 白皮阿草 / 黑皮阿草（小黑·尼驼），以及五种蝴蝶结颜色对应不同成员。

建议把「阿草的蝴蝶结」做成**随装配角色变色**的装备：装配在贝拉身上显示橙色蝴蝶结并在描述里换一句台词，装配在嘉然身上显示黄色。这样只用一件装备就产生了多种读法，成本极低、辨识度极高，也最贴合「枝江」的社区默契。

### 11.4 顺带发现

1. **`dafenggou`（大凤沟火锅底料）与「火锅」梗是同一出处**，已在第六节设计。本次新增时可把它的 quote 换成更贴乃琳的一句：「你们比火锅重要多了。」
2. **`haoting-key` 好听的钥匙** 现有 `allowedTypes` 含 `naiqilin`，与梗清单里「好听的」是贝拉的口头禅（题库第 36 题）——两点需分清：钥匙的命名偏「好听的歌」，而「好听的」本身是贝拉梗，别混用。
3. **`xilanai`（喜拉乃）与 `jiaxinnaitang`（嘉心奶糖）都含奶淇琳**，是乃琳粉丝梗唯一能触达融合卡的路径，故 A/S 件尽量挂上这两个 id，避免融合卡长期缺装备（呼应第五节）。
